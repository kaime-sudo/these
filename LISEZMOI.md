# Thèse

Séances de rédaction chronométrées, pages écrites, date de fin estimée et bilan pour le directeur. Les données restent dans le navigateur de l'ordinateur (IndexedDB).

## Mise en ligne
Nouveau dépôt GitHub public `these`, contenu de ce dossier à la racine, puis Settings > Pages > Deploy from a branch > main, /(root).
Adresse : `https://TON-NOM.github.io/these/`. Dans Chrome ou Edge sur ordinateur : icône d'installation dans la barre d'adresse.

## Mise à jour
Change `v1` dans `sw.js` (constante `CACHE`) à chaque envoi de fichiers modifiés.

## Sauvegarde
Exporte chaque semaine (Réglages). Ne dépose jamais la sauvegarde dans le dépôt public.
